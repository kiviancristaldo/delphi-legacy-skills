# Ícones

Glifos da fonte **Segoe Fluent Icons** (Windows 11) ou **Segoe MDL2 Assets** (Windows 10): o
componente escolhe a que existir (`FonteIcones`). Os códigos são os mesmos nas duas. Só os grupos
principais do menu, a marca e os botões têm ícone; as opções dentro dos grupos ficam só com texto e
a linha guia, como num menu web.

| Constante | Glifo | Use para |
|---|---|---|
| `C_ICONE_INICIO` | casa | início, painel |
| `C_ICONE_AGENDA` | calendário | agenda, agendamentos |
| `C_ICONE_CADASTROS` / `C_ICONE_ESTOQUE` | livros | cadastros, tabelas, estoque |
| `C_ICONE_PESSOAS` | pessoas | clientes, pacientes, RH, profissionais |
| `C_ICONE_MOVIMENTOS` | setas de troca | movimentos, lançamentos |
| `C_ICONE_DOCUMENTO` / `C_ICONE_PEDIDOS` | documento | pedidos, fichas, avaliações, notas |
| `C_ICONE_CARRINHO` | carrinho | vendas, PDV |
| `C_ICONE_RELATORIOS` | gráfico | relatórios |
| `C_ICONE_SAUDE` | coração | atendimentos, saúde |
| `C_ICONE_PASTA` | pasta | "Arquivos" |
| `C_ICONE_SISTEMA` | engrenagem | sistema, parâmetros, configurações |
| `C_ICONE_CALCULADORA` | calculadora | financeiro, cálculos |
| `C_ICONE_IMPRESSORA` | impressora | impressão |
| `C_ICONE_EMAIL` | envelope | e-mail, contatos |
| `C_ICONE_SOBRE` / `C_ICONE_INFO` | "i" | sobre, informação |
| `C_ICONE_SAIR` | liga/desliga | botão Sair (usado pelo rodapé do menu) |
| `C_ICONE_BUSCA` | lupa | busca |
| `C_ICONE_SUCESSO`, `C_ICONE_AVISO`, `C_ICONE_ERRO`, `C_ICONE_PERGUNTA` | estados | diálogos |
| `C_ICONE_SALVAR`, `C_ICONE_EXCLUIR`, `C_ICONE_ADICIONAR`, `C_ICONE_EDITAR`, `C_ICONE_FECHAR` | ações | botões |

Outro glifo: qualquer código da tabela "Segoe MDL2 Assets icons" da Microsoft, como string
`#$E8xx`. Confira o código antes de usar (glifos parecidos têm códigos vizinhos).
